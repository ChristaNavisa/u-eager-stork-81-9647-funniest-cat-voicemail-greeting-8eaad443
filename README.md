Entry for [Funniest Cat Voicemail Greeting](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443) on make.fun.

The program writes one line to `/output/entry.txt`: the voicemail greeting
a cat named Miso would record — asleep on the clean laundry, demanding food
at 4 a.m., and closing with the reversal that she will not answer either way.
The gate requires 1–120 characters of UTF-8 text on one line; this entry is
116 characters on one line, no trailing newline.

> Hi, it's Miso. I'm asleep on your clean laundry. Leave food at 4 a.m. or don't call back. I won't answer either way.

Run with Node 22+:

```sh
node main.ts
```
